# xtech789

Nu Skin E-Commerce Web Application built with React, Vite, and Tailwind CSS.

## Features
- **Modern Responsive UI**: Built to match Figma design specifications.
- **Dynamic Product Catalogue**: Diverse product lines with categories, tags, specifications, and descriptions.
- **Search System**: Real-time keyword filtering across names, categories, descriptions, and specifications.
- **Wishlist Management**: Persistent wishlist drawer with live header count and instant add/remove actions.
- **Cart & Checkout**: Interactive shopping cart drawer with quantity controls and live subtotal calculations.
- **Infinite Carousel Banner**: 3-second autoplay hero banner with seamless infinite loop animation.
- **Awards Carousel**: Multi-page international awards slider with interactive pagination dots.

## Tech Stack
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## Getting Started
```bash
npm install
npm run dev
```
